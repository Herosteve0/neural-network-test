# Neural Network test project
This is my first deep dive into neural networks and how they function both mathematically and in computers.

This specific model I made uses Scalar and Parallel (SIMD) computation methods and I plan to add more options in a new project I am working on,
which will be a more polished version of this.

This is a unity project and I highly recommend it if you are just learning about the core idea of Neural Networks, which consists of three variations:
- Mathematically correct (Educational)
- Scalar
- And SIMD, which is the best this version has to offer (Parallel)

I won't make any promises that the code is as optimized as it could, but I think it's clean enough for people to learn about it.
Feel free to use this code to expand upon this project or, if you find it worthy, use it for teaching!
